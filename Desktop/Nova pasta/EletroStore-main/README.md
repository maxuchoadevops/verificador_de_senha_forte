## 📌 Sobre o Projeto

Este projeto consiste em uma **Tela de Login** moderna criada como parte do desenvolvimento da aplicação **DripStore**. O foco principal foi estruturar um design limpo, centralizado e intuitivo, contando com campos de autenticação tradicionais e opções de login social (Google e LinkedIn).

---

## ✨ Funcionalidades

- 🎨 **Design Moderno & Responsivo**: Centralização perfeita com Flexbox e estilização customizada via CSS.
- 🖼️ **Identidade Visual**: Logotipo integrado e tipografia profissional utilizando a fonte **Inter** do Google Fonts.
- 🔐 **Campos de Acesso**: Inputs dedicados para usuário/e-mail e senha (ocultamento de caracteres).
- 🔗 **Links Úteis**: Atalhos para recuperação de senha ("Esqueceu a senha?") e redirecionamento para a página de cadastro.
- 🌐 **Autenticação Social**: Botões estilizados com ícones oficiais para login rápido via **Google** e **LinkedIn**.

---

## 🛠️ Tecnologias Utilizadas

As principais ferramentas e bibliotecas utilizadas no desenvolvimento deste projeto:

* **[React](https://react.dev/)** - Biblioteca JavaScript para construção de interfaces baseadas em componentes.
* **[Vite](https://vite.dev/)** - Empacotador e ferramenta de build ultrarrápida para desenvolvimento web.
* **[React Router DOM](https://reactrouter.com/)** - Biblioteca de gerenciamento de rotas e navegação.
* **[React Icons](https://react-icons.github.io/react-icons/)** - Biblioteca de ícones vetoriais para os botões sociais.
* **CSS3** - Estilização modularizada e responsiva.

## 🚀 Como Executar o Projeto Localmente

Siga os passos abaixo para clonar e rodar o projeto na sua máquina:

### 1. Pré-requisitos
Certifique-se de ter o **Node.js** instalado em seu computador.

### 2. Clonar o repositório
```bash
git clone https://github.com/maxuchoadevops/EletroStore

3. Acessar a pasta do projeto
Bash
cd seu-diretorio/dripstore # (Ajuste para o nome da sua pasta local)
4. Instalar as dependências
Bash
npm install
5. Iniciar o servidor de desenvolvimento
Bash
npm run dev
Pronto! O terminal indicará um endereço local (geralmente http://localhost:5173/login) para você abrir no navegador.
